BRIGHT HIGH SCHOOL LUWERO — ACTIVITY 7.0 MISSING HTML PAGES

Included pages:
- services.html  (programme table with six data rows and merged cells)
- gallery.html   (eight images with alternative text and captions)
- media.html     (video player with a text alternative and caption-track reference)
- faq.html       (five expandable FAQ entries using details and summary)

INSTALLATION
1. Copy all four HTML files into the same main/root folder as index.html,
   about.html, academics.html, admissions.html, student-life.html and contact.html.
2. Keep the shared stylesheet in css/style.css.
3. Ensure the images referenced in gallery.html exist in the images folder.
4. Put your video at media/school-introduction.mp4, or edit the video source
   path in media.html to match your actual video file.
5. Add links to these four pages to the navigation and footer of the existing
   pages so visitors can reach them consistently.

CHECK BEFORE SUBMISSION
- Confirm school facts, staff names, programme details, fees, phone numbers,
  email addresses and location details with the real school.
- Optimise every gallery image to less than 200 KB as required by Activity 7.0.
- Test every internal link and run each page through the W3C HTML Validator.
- The contact page is a separate existing file and should retain its validated
  enquiry form, embedded map, address and opening hours.
